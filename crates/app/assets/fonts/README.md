# Fonts

The UI uses **Inter**, which is embedded into the binary at compile time (`src/app.rs`).

The build needs one file here:

| File | Source |
| :--- | :--- |
| `InterVariable.woff2` | <https://rsms.me/inter/download/>. Unzip it and take `web/InterVariable.woff2` |

Inter is © The Inter Project Authors and licensed under the **SIL Open Font License 1.1** (OFL-1.1), which is compatible with GPL-3.0 distribution. Keep the font's `LICENSE.txt` next to it as `OFL.txt` when you add the file.
