# DocumentKit

An open-source, cross-platform desktop toolkit for working with PDFs — organize, optimize, convert, edit, secure, and analyze documents locally.

![Platforms](https://img.shields.io/badge/platforms-Windows%20%7C%20macOS%20%7C%20Linux-blue)
![Built with Rust](https://img.shields.io/badge/built%20with-Rust-orange)
![License: GPL v3](https://img.shields.io/badge/license-GPLv3-green)
![Status](https://img.shields.io/badge/status-in%20development-yellow)

> **Status:** Early development. Features below are planned and tracked in the roadmap.
